# Miranda Beitel — Engineering Portfolio

Personal portfolio site: projects, interests, resume and contact.

Plain HTML/CSS/JS, no build step. Hosted with GitHub Pages.

- `index.html` — the whole site (pages are switched with `#home`, `#projects`, `#resume`, …)
- `img/` — photos, renders and drawings
- `resume.pdf` — the downloadable resume (replace this file to update it)
